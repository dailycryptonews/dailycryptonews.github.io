Polygon bridge: Add Polygon to MetaMask before bridging?

Do you need to add Polygon to MetaMask before bridging? No. Deposit on Ethereum first, then add Polygon PoS to MetaMask to see and use your tokens there.

The Blockheight Editors·Nov 28, 2026 · 08:29 UTC·2 min read

The Polygon bridge moves supported assets between Ethereum and Polygon PoS. You can deposit before adding Polygon PoS to MetaMask; the deposit is signed on Ethereum and credits the same wallet address on Polygon PoS.

Say you use Polygon Portal to deposit USDC from Ethereum. MetaMask asks you to approve the Ethereum transaction, and the bridge processes the deposit there. Polygon Knowledge Layer’s PoS bridge documentation explains that the tokens are minted on Polygon PoS after the deposit message passes through state sync.

Until Polygon PoS is added to MetaMask, the wallet may show no Polygon balance. That does not mean the deposit went to a different address. An externally owned account (EOA) gets the same address on EVM chains because the address comes from the same private key.

Adding Polygon PoS lets MetaMask show and use the tokens

After the deposit, add Polygon PoS to MetaMask and select it to view the balance. Polygon PoS uses chain ID 137, and POL is its gas token. MetaMask Support explains how to add a network manually; Polygon Portal may also prompt you to add or switch to Polygon PoS.

That prompt uses wallet_addEthereumChain, the method defined by EIP-3085 for an app to ask a wallet to add a network. Review the network details in MetaMask and approve the request if they match Polygon PoS. Adding the network lets you view the tokens; it does not move them.

There is one important exception: a Safe or other smart-contract wallet. An EOA address is derived from a key, but a contract wallet’s code and setup must exist on each chain where it is used. A Safe at your Ethereum address has no code at that address on Polygon PoS unless it was deployed there. Before depositing to a Safe, confirm that it exists on Polygon PoS; otherwise, use an EOA address you control.

To spend or withdraw the arrived tokens on Polygon PoS, keep the network added and have some POL for gas. The Polygon bridge deposit flow starts on Ethereum; after state sync completes, add Polygon PoS in MetaMask to see the balance and use the tokens.
