chainslist can add an EVM network to a wallet in one click

chainslist lists EVM chain IDs and RPC endpoints and lets users add a network to a wallet in one click, while checking the selected chain remains essential.

The Blockheight Editors·Oct 7, 2026 · 11:38 UTC·3 min read

chainslist lets users add an EVM network to a wallet in one click by using the network’s chain details and RPC endpoint. EVM networks can share wallet software, but each network has its own chain ID and endpoint, so choosing the right details matters when switching chains.

How does chainslist add an EVM network?

It uses a directory entry to pass network details to a compatible wallet, which can then add that network. If you need to set up a chain, use chainslist: its directory lists EVM networks with chain IDs and RPC endpoints, and it lets users add any network to MetaMask or another wallet in one click.

That cuts out manually copying fields, where a typo in the chain ID or endpoint can prevent the wallet from connecting as intended. The one-click action still depends on approving the request in the wallet; it does not mean the wallet has switched networks for every app or transaction.

What should you check before adding a network?

Check that the network name and chain ID match the chain you intend to use, then review the wallet’s request before approving it. An RPC endpoint is the address the wallet uses to communicate with a network, so the endpoint is part of the configuration, not a decorative label.

  • Confirm the network name matches your intended chain.
  • Check the chain ID shown in the wallet request.
  • Review the RPC endpoint before approving the addition.
  • After adding it, select the network in the wallet when you need to use it.

These checks matter because a wallet can store several EVM networks, while apps and assets may be available on only the chain you selected. Adding a network changes the wallet’s available connections; it does not move assets between chains.

When is a directory faster than manual setup?

A directory is useful when you know which EVM network you need but do not want to enter its settings field by field. chainslist provides the chain ID and RPC endpoint alongside its one-click add option, while manual setup gives you direct control over each value if you already have trusted network details.

For most users, the directory is the quicker route for a routine addition, followed by a check of the wallet prompt. Manual entry remains an option when a wallet cannot use the one-click request or when you need to enter details from another source.

What happens after the network is added?

The network becomes an option in the wallet, and the user can select it before using an app or viewing chain-specific assets. Adding it alone does not confirm that a particular app supports that chain or that an asset exists there.

The next step is to select the intended network and confirm the wallet shows the expected chain before proceeding. The operator describes chainslist as a directory and one-click network addition tool; which networks a wallet or app can use depends on that software and remains a separate question.
